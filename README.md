# Risk Normalization Does Not Imply Scale Invariance

Public replication companion for *Risk Normalization Does Not Imply Scale
Invariance: Costs, Harmonic Width, and Eligibility in Futures Trading Rules* by
Ariel Elboim.

- SSRN submission: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7388259
- Permanent replication archive: https://doi.org/10.5281/zenodo.22230814
- ORCID: https://orcid.org/0009-0001-1341-366X

The SSRN submission is currently under completeness review. The Zenodo record
is the citable, immutable archive for version 1.0. This repository is the
maintained working view of the same public replication materials.

## Contents

This archive accompanies *Risk Normalization Does Not Imply Scale Invariance: Costs, Harmonic Width, and Eligibility in Futures Trading Rules* by Ariel Elboim, Working Paper Version 1.0, September 1, 2026.

The archive contains the public manuscript source, versioned analysis scripts, derived audit outputs, figure sources, frozen protocols, source-repair documentation, calendar reconciliation, chronology and eligibility-provenance audits, and a SHA-256 manifest.

The commercially licensed Sierra Chart and Databento source data are not redistributed. Reproduction of the raw-data pipeline requires independent access to those sources. The included public artifacts allow verification of the reported derived quantities and document the exact canonical inputs expected by the scripts.

## Reproduction

Run `work/research_factory/runs/diagnostics/reproduce_orb_scale_paper_package.py` from the project root after placing licensed canonical source files at the paths described by the public manifests. The runner rebuilds the central derived outputs and regenerates the three figures.

The raw contract-file inventory was not present when this public package was built. Consequently, exact within-file duplicate minute timestamps in those licensed raw files were not counted. The manuscript does not infer that count from the duplicate-free continuous artifacts.
