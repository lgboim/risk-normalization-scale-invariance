# Security and responsible disclosure

This is a research-software repository. The main risks are accidental disclosure of credentials, private paths, licensed data, or vendor material.

## Do not report publicly

Do not open a public issue containing:

- API keys, tokens, passwords, cookies, or private URLs;
- licensed Sierra Chart or Databento data;
- personally identifying information not already part of the public paper;
- a reproducible path to extracting non-public third-party material.

For a sensitive report, contact the maintainer at `lgboim@gmail.com` with the subject `risk-normalization repository disclosure`. Include only the minimum information needed to reproduce the problem. Do not attach licensed data.

Ordinary numerical discrepancies, documentation errors, and non-sensitive reproduction failures should use the public issue templates.
